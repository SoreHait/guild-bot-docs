# 中二节奏 (CHUNITHM 国服)

***中二节奏***是一款街机音乐游戏，目前**仅支持国服**。使用前请前往要使用的查分器绑定 QQ 账号，若使用落雪查分器则还需要在 ChieriBot 上进行额外认证，认证方法见下文。


## 支持查分器列表及相关操作

目前 ChieriBot 中二节奏模块所支持的 API 如下：
- 查分器 APP (louis)  **默认 API**
- [落雪查分器 (lxns)](https://maimai.lxns.net)
- [水鱼查分器 (divingfish)](https://www.diving-fish.com/maimaidx/prober/)

### 各 API 绑定方法

- 查分器 APP (louis)
  - 在查分器 APP 中打开设置 - 账号关联，输入 QQ 号绑定即可使用全部功能
- 落雪查分器 (lxns)
  - 点击左侧菜单账号详情，选择第三方应用，输入 QQ 号并点击保存即可使用 B50 查询
  - 在 ChieriBot 使用 `/chu lxauth` 指令进行授权认证即可使用分数列表功能，认证流程见下文
- 水鱼查分器 (divingfish)
  - 点击右上角编辑个人资料，在绑定 QQ 号中输入 QQ 号，点击保存即可使用 B50 查询
  - 不支持分数列表查询

### 切换 API

- `/chu switch`
  - 切换至下一个 API
  - 顺序为 louis -> lxns -> divingfish
- `/chu switch [API]`
  - 切换至指定的 API

### 落雪查分器授权认证流程

1. 在 ChieriBot 使用 `/chu lxauth` 指令获取认证链接
   - **请注意**：该链接中包含随机生成的字符串，用于与认证人唯一对应，因此每人的认证链接都不一样，**请勿修改链接或使用他人的链接进行认证**
2. 点开认证链接并登录你的账号，授权 ChieriBot 后网页会显示一个授权码，点击复制
3. 发送 `/chu lxauth [你的授权码]`，如 `/chu lxauth YJSP-1145-0810`，此时 Bot 会告知绑定成功与否，若成功会一并返回绑定的玩家 ID，请确认是否绑定正确
   - 认证方法采用 `PKCE`，即该授权码只能被认证发起人使用，且为一次性的，因此无需撤回
4. 若确认玩家 ID 正确，则绑定成功

注：单次认证的有效期为 30 天，重新认证或查询分数列表都可以刷新有效时长


## 查询 Best 50

注：以下指令中`b50`亦可为`b30`

### 查询自己 QQ 绑定账号的 B50

- `/chu b50`

### 查询特定用户的 B50

- `/chu b50 [用户名]`
  - **请注意**：使用 louis/divingfish 时，`[用户名]`处填入的是要查询用户的**查分器用户名**而不是玩家 ID
  - 使用 lxns 时，`[用户名]`处填入的是要查询用户的**好友码**


## 查询特定等级的分数列表

注：以下指令中`[等级]`处填入等级**而非定数**，如 14/14+/15/15+，支持范围 10 - 15+

**请注意**：本功能仅支持 louis 与 lxns，且 lxns 需要授权认证，具体方法见上文

### 查询自己 QQ 绑定账号的分数列表

- `/chu list [等级]`

### 查询特定用户的分数列表

- `/chu list [等级] [用户名]`
  - **请注意**：本指令仅支持 louis 使用
  - 由于 lxns 需要授权，因此不可查询他人的分数列表（除非使用他人查分器账号在你的 QQ 上进行认证）

### `list` 指令变体

由于需要使发出的图片体积尽可能小，`list` 指令是**不保留未游玩谱面**的

若需要查询**保留未游玩谱面**的分数列表，请将 `list` 替换为 `listall`
